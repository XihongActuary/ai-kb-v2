三十秒选定模型

你的情况先用这个为什么
要预测一个数字，关系大致是直的线性回归 / GLM 系数能直接念给人听，出事好解释
要预测「会不会」（0/1）逻辑回归 输出就是概率，天然能排序、能设阈值
要预测次数、金额，且大部分是 0泊松 / Tweedie 专门为正数、零膨胀、长尾设计
表格数据，想要精度，也要看变量重要性GBDT / XGBoost 表格数据上的常胜将军
要写成「如果…就…」给人审核决策树（浅一点） 规则能原样导出成文字
没有标签，只想把人分堆K-Means 快、结果看得懂
特征太多、彼此相关PCA 压成几个互不相关的新变量
图像 / 文本 / 语音神经网络 这些任务上传统模型打不过它
表格数据（一行一个客户、几十个字段）上， GBDT 类通常打过深度学习，而且训练快、好解释。 别因为「深度学习听起来更高级」就先上它。

线性回归Linear Regression

是什么找一条直线（或超平面），让所有点到它的竖直距离平方和最小。
何时用要预测的是连续数字，且相信各项影响可以相加：保费 = 基础 + 车龄×a + 驾龄×b …
怎么用先看残差图有没有弯曲；有弯就加平方项或换模型。系数正负要和业务常识对得上。
数学表达
ŷ = β₀ + β₁x₁ + β₂x₂ + … + βₚxₚ   ·   目标：min Σ(yᵢ − ŷᵢ)²
红线是拟合出来的直线，每个点到线的竖直虚线就是误差
本案例没用目标变量是出险次数与金额，不是正态分布的连续值，所以本案例走的是它的推广——GLM：models.py · PoissonRegressorL134–210
Python 代码（点击展开）
import numpy as np

# 造点数据：y = 3 + 2x + 噪声
rng = np.random.default_rng(0)
X = rng.uniform(0, 10, size=200)
y = 3 + 2 * X + rng.normal(0, 1.5, size=200)

# 加一列 1，用来吸收截距
A = np.column_stack([np.ones(len(X)), X])

# 闭式解（正规方程）：一步算出系数
beta = np.linalg.solve(A.T @ A, A.T @ y)
print("截距=%.2f  斜率=%.2f" % (beta[0], beta[1]))   # ≈ 3.0, 2.0

# 预测 + 评估
pred = A @ beta
print("RMSE = %.3f" % np.sqrt(np.mean((y - pred) ** 2)))

逻辑回归Logistic Regression

是什么名字里有「回归」，干的是分类：先算线性得分，再用 S 形函数压成 0–1 之间的概率。
何时用要判断「属不属于某一类」，而且想要概率而不只是结论——比如要按概率排序再圈人。
怎么用输出是概率，阈值你自己定；调阈值就是调「宁可错杀还是宁可放过」。别只看准确率。
数学表达
p = 1 / (1 + e^(−(β₀ + β₁x₁ + …)))   ·   训练：最大化对数似然 Σ[y·ln p + (1−y)·ln(1−p)]
S 曲线把得分压成概率；中间那条竖线是判定阈值
本案例没用本库手写了它，但只在正确性自检里跑（解析解 vs 数值解互印），主流水线没走这条路——因为「好司机」这条线最后是排序＋圈选，概率只是副产品，不是决策依据。实现见 models.py · LogisticRegressionL214–274，自检见 test_models.py
Python 代码（点击展开）
import numpy as np
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import roc_auc_score

rng = np.random.default_rng(0)
X = rng.normal(size=(600, 3))
y = (X @ np.array([1.2, -0.8, 0.5]) + rng.normal(0, .6, 600) > 0).astype(int)

m = LogisticRegression(penalty="l2", C=1.0, max_iter=1000)
m.fit(X, y)

p = m.predict_proba(X)[:, 1]          # 要概率，不要硬结论
print("AUC = %.3f" % roc_auc_score(y, p))

# 阈值不是非得 0.5：想少漏人就调低，想少误伤就调高
for t in (0.3, 0.5, 0.7):
    pred = (p >= t).astype(int)
    print("阈值 %.1f → 圈出 %d 人，命中 %d 人" % (t, pred.sum(), (pred & y).sum()))

GLM 与泊松回归Generalized Linear Model / Poisson

是什么线性回归的推广：允许结果不是正态分布。泊松回归专为计数（出险次数）设计，用对数连接把「线性得分」变成「正的期望值」。
何时用要预测次数、件数、频率这类非负整数；精算里的索赔频率建模就是它。
怎么用看偏差（deviance）是否收敛；检查预测均值与实际的比值（校准比）。有过度离散要考虑负二项。
数学表达
ln μ = β₀ + β₁x₁ + …  →  μ = e^(β₀ + β₁x₁ + …)   ·   y ~ Poisson(μ)，权重用暴露数
指数曲线保证预测值永远是正数
本案例本案例的主模型之一。频率建模就是它，IRLS 手写实现：models.py · PoissonRegressorL134–210
Python 代码（点击展开）

本库的 PoissonRegressor 是手写的（IRLS 迭代），见 models.pyL134–210。

import numpy as np, statsmodels.api as sm

rng = np.random.default_rng(0)
n = 2000
x = rng.normal(size=n)
exposure = rng.uniform(0.4, 1.0, size=n)        # 暴露数：保了多久
mu = np.exp(0.3 + 0.6 * x) * exposure           # 真正的期望次数
y = rng.poisson(mu)

# 泊松 GLM：对数连接 + 暴露数作 offset
m = sm.GLM(y, sm.add_constant(x), family=sm.families.Poisson(),
           offset=np.log(exposure)).fit()
print(m.summary())
print("偏差 deviance = %.1f，自由度 df = %d" % (m.deviance, m.df_resid))
print("系数 =", np.round(m.params, 3))          # ≈ [0.3, 0.6]

Tweedie 回归Tweedie Regression

是什么专门对付「一大堆 0 ＋ 少数巨额」的金额：把「会不会出险」和「出险赔多少」揉进一个分布里一次建模。
何时用直接预测纯保费（金额）：大多数人一年赔 0 元，极少数赔到几十万。本案例最后就是这么干的。
怎么用调 power 参数 p（1<p<2，1.5 常用）。别用 MSE 当主指标，零太多会把它压得没有意义。
数学表达
Var(μ) = φ·μ^p，p ∈ (1, 2)   ·   纯保费 = 频率 × 案均 = μ_freq × μ_sev
第一根柱子是「赔 0 元」的人，右边那几根是巨额赔案
本案例没用本库明确没实现，在第 25 页写成了诚实声明：03 页 · Tweedie 留作练习。案例改用「频率 × 案均」两步拆解达到同一目的。
Python 代码（点击展开）
import numpy as np, statsmodels.api as sm

rng = np.random.default_rng(0)
n = 3000
x = rng.normal(size=n)
mu = np.exp(0.5 + 0.4 * x)

# Tweedie 造数（简化）：先抽次数，再抽伽马金额
cnt = rng.poisson(mu * 0.25)
sev = rng.gamma(shape=2.0, scale=3000, size=n)
y = cnt * sev                                   # 大多数是 0

# power=1.5 是纯保费建模的常用档位
m = sm.GLM(y, sm.add_constant(x),
           family=sm.families.Tweedie(var_power=1.5, link=sm.families.links.Log())
           ).fit()
print("power=1.5 时的系数 =", np.round(m.params, 3))

# 别忘了：零占比高时，先看「预测均值 / 实际均值」
print("校准比 = %.3f" % (m.fittedvalues.mean() / y.mean()))

决策树Decision Tree (CART)

是什么一串「是非题」：先问最能分清好坏的那个问题，把人劈成两半，两半里再各自问。
何时用要的是能念给人听的规则；或者数据里有明显的分段（比如 25 岁以下一个价、以上另一个价）。
怎么用限深度（3–6 层）和叶子里最少样本数，否则一个叶子一个人，等于背答案。
数学表达
回归树：叶子里取均值  ·  分裂准则：min [ n_L·Var_L + n_R·Var_R ]；分类树改用基尼或熵
一层一层问下去，叶子是结论
本案例单树用来产出能给核保看的规则：models.py · DecisionTreeRegressorL278–391
Python 代码（点击展开）

手写版（含「怎么挑最佳切点」）见 models.py · DecisionTreeRegressorL278–391。

from sklearn.tree import DecisionTreeRegressor, export_text

# 关键旋钮就是这两个：别让它长得太深、叶子别太小
m = DecisionTreeRegressor(max_depth=4, min_samples_leaf=40, random_state=0)
m.fit(X, y)

print("叶子数 =", m.get_n_leaves(), " 深度 =", m.get_depth())
# 规则可以直接念给业务听

# 用它预测
print(m.predict(X[:5]))

随机森林Random Forest

是什么一堆树各看一部分数据、各看一部分特征，最后投票/取平均。单棵树容易走偏，一群树的平均就稳了。
何时用要稳、不想调参、又想要非线性。是「先跑一个不丢人」的基线模型。
怎么用树数 300–500 够了，再加收益很小。想提速可以砍 max_depth。它给不了「公式」，但能给特征重要性。
数学表达
ŷ = (1/B) Σ f_b(x)   ·   每棵树：样本自助抽样 + 每次分裂只看随机 m 个特征
三棵树各自给个数，平均一下就是最终答案
本案例没用没用。案例要能落成核保规则的单一路径，几百棵树投票说不清；精度上也被 GBDT 压过，见 第 28 页。
Python 代码（点击展开）
from sklearn.ensemble import RandomForestRegressor

m = RandomForestRegressor(n_estimators=400,      # 树数：300~500 够用
                          max_depth=6,           # 不限深会又慢又容易过拟合
                          min_samples_leaf=30,
                          n_jobs=-1, random_state=0)
m.fit(X, y)

# 谁最重要？做特征筛选、跟业务解释都靠它
imp = sorted(zip(m.feature_importances_, names), reverse=True)

GBDT / XGBoostGradient Boosting Decision Trees

是什么一棵接一棵地补：第一棵树粗粗预测，第二棵专补第一棵的残差，第三棵再补剩下的……最后加起来。
何时用表格数据要精度时的第一选择。kaggle 和精算实务里最常见的赢家。
怎么用三个旋钮：树数（配 early_stopping）、学习率（0.05–0.1）、树深（3–6）。学习率调小就要多加树。别忘留验证集做提前停止。
数学表达
F_m(x) = F_{m−1}(x) + η·h_m(x)，其中 h_m 去拟合残差 −∂L/∂F
柱子一根比一根矮：后面的树只补剩下的残差
本案例本案例精度最高的模型，且要跟 GLM 对垒看谁更能往外走：models.py · GBDTL395–539 · step45 四模型对垒L233–459

KNNK-Nearest Neighbors

是什么不训练，只记住所有人；来一个新人，就找跟他最像的 K 个邻居，看邻居们怎么样。
何时用样本不大、特征不多、想做个直观的对照基线。也常用于填补缺失值。
怎么用必须标准化，否则量纲大的特征会一个人说了算。K 太小会抖，太大会抹平边界。样本一大就慢。
数学表达
ŷ(x) = (1/K) Σ_{i ∈ N_K(x)} y_i   ·   距离常用欧氏：d = √Σ(x_i − x_j)²
虚线圈住最近的 K 个邻居，少数服从多数
本案例没用没用。KNN 给不出系数或规则，核保要能解释为什么拒；而且十几个特征里有类别型，距离本身没意义。
Python 代码（点击展开）
from sklearn.neighbors import KNeighborsRegressor
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline

# KNN 对量纲极度敏感：标准化必须做，且要放进 pipeline 防泄漏
m = make_pipeline(StandardScaler(),
                  KNeighborsRegressor(n_neighbors=15, weights="distance"))
m.fit(X, y)

print("预测 =", m.predict(X[:3]))
# weights="distance"：越近的邻居说话越算数

SVMSupport Vector Machine

是什么不光找一条分界线，还要找一条离两边都最远的分界线。只有边界上那几个点（支持向量）说了算。
何时用样本不算大、特征维度高、边界清晰；文本分类的经典选择。
怎么用先标准化。核函数选 rbf 时，C 和 gamma 要调。样本上万就慢了，而且不直接给概率。
数学表达
min ‖w‖²/2 + C·Σξ_i，约束 y_i(wᵀx_i + b) ≥ 1 − ξ_i   ·   核技巧：k(x, x′) = exp(−γ‖x−x′‖²)
SVM 要的是「最宽的马路」，不是随便一条线
本案例没用没用。同样卡在可解释性上——强监管下「算不出来为什么」就等于不能用。
Python 代码（点击展开）
from sklearn.svm import SVC
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline

clf = make_pipeline(StandardScaler(),
                    SVC(kernel="rbf", C=1.0, gamma="scale",

K-MeansK-Means Clustering

是什么没有答案也要分组：先随便定 K 个中心，把每个人派给最近的中心，再把中心挪到队员的均值处，反复到不动。
何时用想把客户分成几类却说不清标准；或者做探索，看看数据里是不是天然有几堆。
怎么用先标准化。K 要自己定（常用肘部法或多试几个看业务能不能解释）。多跑几个随机起点取最优。
数学表达
目标：min Σ_{k} Σ_{x ∈ C_k} ‖x − μ_k‖²   ·   μ_k = C_k 里所有点的均值
两堆点各自围绕自己的中心
本案例没用没用。本案例标签是算出来的（真实纯保费是否低于 1,063 元），不是要机器自己分组，见 第 24 页 · 标签从哪来。
Python 代码（点击展开）
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler

Xs = StandardScaler().fit_transform(X)      # 聚类前必须标准化

# 肘部法：换个 K 看「簇内紧密程度」下降的拐点
for k in range(2, 7):
    km = KMeans(n_clusters=k, n_init=10, random_state=0).fit(Xs)
    print("K=%d   inertia=%.1f" % (k, km.inertia_))

km = KMeans(n_clusters=3, n_init=10, random_state=0).fit(Xs)
print("每个人被分到：", km.labels_[:20])
print("簇中心（标准化尺度）=", km.cluster_centers_.round(2))

PCAPrincipal Component Analysis

是什么特征太多又互相相关时，把它们重新组合成少数几个互不相关的新变量，尽量不丢信息。
何时用几十上百个特征、彼此高度相关；或者想画散点图但数据是高维的。
怎么用先标准化。看「累计解释方差」选保留几个（常取 80–95%）。注意：主成分不好解释，要解释就用原变量。
数学表达
找 w 使 Var(Xw) 最大，且 ‖w‖ = 1   ·   即 XᵀX 的特征向量；解释比例 = λ_i / Σλ
点云最伸展的方向就是第一主成分
本案例没用没用。特征只有十几个，每一个都要能在核保规则里点名，降维之后就说不清是谁在起作用了。
Python 代码（点击展开）
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler

Xs = StandardScaler().fit_transform(X)

p = PCA(n_components=0.9)        # 直接说「保留 90% 的信息」，它会自己算要几个
Z = p.fit_transform(Xs)
print("从 %d 个特征压到 %d 个主成分" % (X.shape[1], Z.shape[1]))
print("各主成分解释比例 =", p.explained_variance_ratio_.round(3))

# 看每个主成分主要由哪些原变量构成（用来给主成分起名字）
print(pd.DataFrame(p.components_, columns=names).round(2))

神经网络 MLPMulti-Layer Perceptron

是什么一堆「加权求和 → 非线性扭转」的小单元层层堆叠，靠反向传播一层层把误差传回去改权重。
何时用图像、语音、文本这类结构复杂的数据；或者特征之间关系高度非线性且样本量极大。
怎么用先标准化。层数别一上来就堆很深，先试一层 64/128 个单元。要 reproducibility 就固定随机种子。
数学表达
h = σ(W₁x + b₁) → ŷ = W₂h + b₂   ·   反向传播：∂L/∂W = ∂L/∂ŷ · ∂ŷ/∂W（链式法则）
三层全连接：线越密，参数越多，也越容易背答案
本案例没用没用。样本 1.1 万条、特征十几个，这个量级上树模型更稳；且神经网络的可解释成本在保险核保里太高，见 第 28 页。
Python 代码（点击展开）
from sklearn.neural_network import MLPRegressor
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline

# 先小后大：一层 64 往往就够了，堆深了只会在表格数据上过拟合
m = make_pipeline(StandardScaler(),
                  MLPRegressor(hidden_layer_sizes=(64,), activation="relu",
                               alpha=1e-3,          # L2，防止背答案
                               max_iter=800, early_stopping=True,
                               random_state=0))
m.fit(X, y)
print("迭代次数 =", m[-1].n_iter_, " 最终损失 =", round(m[-1].loss_, 4))

什么时候别上大模型

诱惑现实该做的
「上深度学习才够先进」 表格数据上 GBDT 通常更好、更快、更好解释 先用 GBDT 做基线，赢不了再换
「树越多越好」 过了一定的量，误差不再降，只是变慢、变难解释 配 early_stopping，看验证曲线拐点
「特征全丢进去让它自己学」 垃圾特征进来，模型只会学到噪声，还会泄漏 先做业务筛选，再看重要性回删
「换个模型就能救回数据问题」 数据本身歪了，什么模型都救不回来 先回到第②步查数据，再看模型
说 人 话

选模型不是追新，是够用 + 能解释 + 能落地。 在保险公司，一个能被核保人听懂、被合规通过的模型， 比一个 AUC 高 0.01 但没人敢用的模型值钱得多。

标准化 / 归一化把不同量纲的特征拉到相近的尺度上，比如都变成「均值 0、标准差 1」。树模型一般不需要。
回归（预测连续值）要预测的结果是一个数字（保额、收入、温度），模型学的是「输入 → 数字」这条映射。
泊松回归专门预测「次数」的 GLM（出险几次、住院几次）。它保证预测出来永远是正数。
概率一件事发生的可能性，写成 0 到 1 之间的一个数。0 是绝不可能，1 是一定发生。
树深与叶子深度 = 从根到叶子一共问了几个问题；叶子 = 走到底的那一片人。树越深分得越细，也越容易把巧合当成规律。
GBDT一棵树不够，就一棵一棵往上加：新树只负责「补前一轮漏掉的部分」，累加起来就很强。
