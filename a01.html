说 人 话

模型是菜，算法是菜谱。同一道菜（线性回归）可以用大火快炒（闭式解，一步算完）， 也可以用小火慢炖（梯度下降，一点一点挪）。菜一样，做法不一样，适用场合也不一样。

闭式解：正规方程Normal Equation / OLS

是什么把「误差平方和最小」这个条件写成方程，一步解出系数，不用迭代。
何时用样本几万以内、特征几十个的线性回归。精算里的 GLM 单机建模基本都够用。
怎么用注意 XᵀX 可能不可逆（特征完全共线），加一点岭回归（ridge）就稳了。样本上百万就别用了，矩阵太大。
数学表达
β̂ = (XᵀX)⁻¹ Xᵀ y   ·   复杂度 O(np² + p³)，p 是特征数
一次矩阵运算直接出结果
本案例没用用不上。GLM 没有闭式解，只能迭代——这正是它比线性回归难一点的原因：PoissonRegressor.fitL161–195
Python 代码（点击展开）
import numpy as np

def ols(X, y, ridge=1e-8):
    """闭式解。ridge 是给对角线加的一点点，防止 XᵀX 不可逆。"""
    A = np.column_stack([np.ones(len(X)), X])
    return np.linalg.solve(A.T @ A + ridge * np.eye(A.shape[1]), A.T @ y)

beta = ols(X, y)
print("系数 =", np.round(beta, 3))

梯度下降Gradient Descent

是什么站在山坡上，看脚下哪边最陡就往哪边迈一小步，反复走到走不动为止。
何时用样本/特征太多、闭式解算不动时；也是所有神经网络的训练方式。
怎么用学习率是最关键的旋钮：太大来回震荡甚至发散，太小慢得没边。先画损失曲线看它是不是平滑下降。
数学表达
θ ← θ − η·∇θ L(θ)   ·   每轮复杂度 O(np)，η 是学习率
每一步都朝着「更低」的方向迈，步子由学习率决定
本案例GBDT 的「梯度」提升，本质就是在函数空间里做梯度下降：GBDT.fitL479–521
Python 代码（点击展开）
import numpy as np

def fit_gd(X, y, lr=0.05, iters=500):
    n, p = X.shape
    w = np.zeros(p); b = 0.0
    for k in range(iters):
        pred = X @ w + b
        gw = (2 / n) * X.T @ (pred - y)      # 对 w 的梯度
        gb = (2 / n) * (pred - y).sum()      # 对 b 的梯度
        w -= lr * gw                          # 朝梯度的反方向挪
        b -= lr * gb
        if k % 100 == 0:
            print(k, "loss = %.4f" % np.mean((pred - y) ** 2))
    return w, b

w, b = fit_gd(X, y)

随机 / 小批量梯度下降SGD / Mini-batch GD

是什么不看全部数据再挪一步，而是抽一小批就挪一步。方向没那么准，但快得多，还自带一点随机性，反而不容易卡在坑里。
何时用样本上十万、上百万时必用；神经网络的默认训练方式。
怎么用批大小常取 32/64/128/256。 epochs 是「把全部数据过几遍」。记得每轮打乱顺序。
数学表达
θ ← θ − η·∇θ L(θ; B)，B 是一小批   ·   一轮 = 把所有批次过一遍；一次 epoch = 看完一轮全量数据
小批量路径更抖，但每一步便宜得多
本案例没用没用。样本才 1.1 万，一次全装进内存；而且 IRLS / 牛顿步更稳、更少调参：PoissonRegressor.fitL161–195
Python 代码（点击展开）
import numpy as np

def fit_sgd(X, y, lr=0.05, epochs=20, batch=64, seed=0):
    rng = np.random.default_rng(seed)
    n, p = X.shape
    w = np.zeros(p); b = 0.0
    for ep in range(epochs):
        idx = rng.permutation(n)               # 每轮打乱，这是必须的
        for s in range(0, n, batch):
            B = idx[s:s + batch]
            pred = X[B] @ w + b
            w -= lr * (2 / len(B)) * X[B].T @ (pred - y[B])
            b -= lr * (2 / len(B)) * (pred - y[B]).sum()
        print("epoch", ep, "loss = %.4f" % np.mean((X @ w + b - y) ** 2))
    return w, b

坐标下降Coordinate Descent

是什么一次只动一个变量，其余全锁住；轮着把所有变量都动一遍，再来第二轮。
何时用目标函数里有些部分不好求导（比如 L1 的尖角）——轮着一个一个来就绕过去了。Lasso 的默认解法。
怎么用变量高度相关时收敛很慢（会来回拉扯）。先做标准化、先去掉完全共线的特征。
数学表达
对每个 j：β_j ← argmin_{β_j} L(β₁,…,β_j,…,β_p)   ·   Lasso 的一步有闭式解（软阈值）
等高线上看，坐标下降只能沿轴向拐直角
本案例没用没用。GLM 的系数之间相关性强，坐标下降收敛慢，不如整体解一步。
Python 代码（点击展开）
import numpy as np

def lasso_cd(X, y, lam=0.1, iters=300):
    """Lasso 的坐标下降：软阈值是关键一步。"""
    n, p = X.shape
    Xs = (X - X.mean(0)) / X.std(0)
    ys = y - y.mean()
    w = np.zeros(p)
    for _ in range(iters):
        for j in range(p):
            r = ys - Xs @ w + Xs[:, j] * w[j]      # 去掉第 j 个变量的贡献
            z = Xs[:, j] @ r / n
            w[j] = np.sign(z) * max(abs(z) - lam, 0) / (Xs[:, j] @ Xs[:, j] / n)
    return w

print("被压成 0 的变量数 =", (np.abs(lasso_cd(X, y)) < 1e-8).sum())

牛顿法Newton's Method

是什么不光看坡度（一阶导数），还看坡度变化的速度（二阶导数），所以能一步跨到接近谷底的位置。
何时用要高精度、参数不算多、目标函数光滑。GLM 的 IRLS 就是它的变体。
怎么用每步要算 Hessian（p×p 矩阵），参数一多就贵。Hessian 可能不可逆，要加阻尼。
数学表达
θ ← θ − H⁻¹ ∇L(θ)，H = ∇²L(θ)   ·   每步 O(p³)，但迭代次数远少于梯度下降
牛顿法一步能跨很远，代价是每步更贵
本案例IRLS 就是牛顿法（泊松对数连接下两者等价）；GBDT 每棵树的叶子值也用了二阶信息：GBDT 的牛顿步长L449–478
Python 代码（点击展开）
import numpy as np

def newton_1d(df, d2f, x0, iters=20, tol=1e-9):
    x = x0
    for k in range(iters):
        g, h = df(x), d2f(x)
        if abs(h) < 1e-12:        # Hessian 接近 0，退回梯度下降那一套
            break
        step = g / h
        x -= step
        if abs(step) < tol:
            break
    return x

# 例：最小化 f(x) = x^4 - 3x^2 + x
root = newton_1d(lambda x: 4*x**3 - 6*x + 1, lambda x: 12*x**2 - 6, x0=0.0)
print("x* =", round(root, 6))

IRLSIteratively Reweighted Least Squares

是什么把「解不了的非线性问题」变成一串能解的加权最小二乘：先猜一次，按当前猜测给每个人算个权重，解一次，再猜……
何时用GLM（泊松、逻辑回归、Gamma）的标准解法。本案例的 Poisson GLM 就是它。
怎么用看偏差（deviance）每轮下降多少，降不动了就停。权重可能爆炸，要加一点岭稳定项。
数学表达
β^{(t+1)} = (XᵀWX)⁻¹ XᵀW z，其中 W = diag( (dμ/dη)² / V(μ) )，z = η + (y−μ)/(dμ/dη)
IRLS 的循环：猜 → 加权 → 解 → 再看
本案例本案例训练 GLM 的那套迭代，手写实现、带收敛判据：PoissonRegressor.fitL161–195
Python 代码（点击展开）

本库实现见 models.py · PoissonRegressor.fitL161–195。

import numpy as np

def poisson_irls(X, y, offset=None, max_iter=80, tol=1e-8, ridge=1e-6):
    """本库手写模型的核心（简化版），见 code/models.py。"""
    n, p = X.shape
    off = np.zeros(n) if offset is None else offset
    beta = np.zeros(p)
    for it in range(max_iter):
        eta = X @ beta + off
        mu = np.exp(np.clip(eta, -20, 20))          # 对数连接
        W = mu                                       # 泊松：权重就是 μ
        z = eta - off + (y - mu) / np.maximum(mu, 1e-8)
        A = X.T @ (X * W[:, None]) + ridge * np.eye(p)
        beta_new = np.linalg.solve(A, X.T @ (W * z))
        if np.max(np.abs(beta_new - beta)) < tol:
            return beta_new, it + 1
        beta = beta_new
    return beta, max_iter

beta, n_iter = poisson_irls(X, y)
print("迭代 %d 次收敛，系数 = %s" % (n_iter, np.round(beta, 3)))

CART 分裂：基尼与熵Gini / Entropy Split

是什么把「哪个问题先问」量化：把两堆人的好坏比例代进公式，算出「混不混」，挑混得最轻的那一刀。
何时用训练决策树 / GBDT 时找最佳切点。本案例的决策树动画就是它。
怎么用连续特征先分箱再找切点（本库分 24 箱）。叶子样本数下限一定要设，否则会切出一个人的叶子。
数学表达
基尼 Gini = 1 − Σp_k²   ·   熵 H = −Σp_k log p_k   ·   选使 n_L·G_L + n_R·G_R 最小的切点
右边那刀把好坏分得干净得多，就选它
本案例单树挑切点用的就是它，带权重版本：DecisionTree._best_splitL312–346
Python 代码（点击展开）

本库实现见 models.py · _best_splitL312–346。

import numpy as np

def gini(y):
    p = np.bincount(y) / len(y)
    return 1 - np.sum(p ** 2)

def best_split(Xj, y, n_bin=24):
    """在一个连续特征上找最佳切点：先分箱，只在箱边界试。"""
    cut = np.quantile(Xj, np.linspace(0, 1, n_bin + 1)[1:-1])
    best = (None, 1e9)
    for c in np.unique(cut):
        L, R = y[Xj <= c], y[Xj > c]
        if len(L) < 30 or len(R) < 30:     # 叶子太小不切
            continue
        g = (len(L) * gini(L) + len(R) * gini(R)) / len(y)
        if g < best[1]:
            best = (c, g)
    return best

c, g = best_split(X[:, 0], y)
print("最佳切点 %.3f，加权基尼 %.4f" % (c, g))

Boosting 前向分步Forward Stagewise / Gradient Boosting

是什么一个一个地加模型：新的那个专门去补「目前还差多少」，加完一起算。每加一个，总误差就该降一点。
何时用弱模型（浅树）叠成强模型。GBDT、XGBoost、LightGBM、AdaBoost 都是这一族。
怎么用学习率 η 控制每棵树的发言权；树太多会过拟合，用验证集 early_stopping 定数量。
数学表达
F_m(x) = F_{m−1}(x) + η·h_m(x)，h_m ≈ 残差 r = y − F_{m−1}(x)（回归）；也可用负梯度替代残差
每棵树只补剩下的残差，串行累加
本案例本案例精度最高的那套，80 轮逐轮补差：GBDT.fitL479–521
Python 代码（点击展开）

本库实现见 models.py · GBDT.fitL479–521。

import numpy as np

def gbdt_scratch(X, y, M=60, lr=0.08, max_depth=3):
    """极简 GBDT：每棵树去拟合当前残差。"""
    from sklearn.tree import DecisionTreeRegressor
    pred = np.full(len(y), y.mean())
    trees = []
    for m in range(M):
        resid = y - pred                      # 还差多少
        t = DecisionTreeRegressor(max_depth=max_depth,
                                  min_samples_leaf=30, random_state=m)
        t.fit(X, resid)                       # 新树专补残差
        pred += lr * t.predict(X)             # 乘学习率后累加
        trees.append(t)
    return trees, pred

_, pred = gbdt_scratch(X, y)
print("RMSE = %.4f" % np.sqrt(np.mean((y - pred) ** 2)))

Bagging 与自助抽样Bootstrap Aggregating

是什么从原数据里有放回地抽好几份，每份各训一个模型，最后投票/平均。抽样的随机性让模型们各不相同，误差就互相抵消了。
何时用模型本身不稳定（深树典型）、想降方差又不想改模型结构。随机森林就是「Bagging + 随机特征」。
怎么用树数越多越稳，但有上限（约 300 后收益微小）。袋外样本（OOB）可以白捡一个验证集。
数学表达
ŷ_bag = (1/B) Σ f_b(x)  ·   每次抽样约 63.2% 的样本会被抽到，剩下的是袋外样本
有放回抽样造出多样性，最后投票
本案例没用没用。没做随机森林——理由同随机森林那条：要单一可解释路径，不要投票。
Python 代码（点击展开）
import numpy as np
from sklearn.tree import DecisionTreeRegressor

def bagging(X, y, B=50, seed=0):
    rng = np.random.default_rng(seed)
    models, oob = [], []
    for b in range(B):
        idx = rng.choice(len(y), len(y), replace=True)   # 有放回
        m = DecisionTreeRegressor(max_depth=None, random_state=b).fit(X[idx], y[idx])
        models.append(m)
        oob.append(np.setdiff1d(np.arange(len(y)), np.unique(idx)))   # 袋外
    return models, oob

# 预测：所有树取平均
def predict(models, X):
    return np.mean([m.predict(X) for m in models], axis=0)

Lloyd 迭代（K-Means 的解法）Lloyd's Algorithm

是什么两步交替：①派点（每人归到最近的中心）→ ②挪中心（移到队员的平均位置）。两步都只会让总距离变小，所以必然停。
何时用训练 K-Means 聚类。也用于向量量化（把连续值压缩成有限档）。
怎么用可能停在局部最优——多跑几个随机起点（n_init=10）取最好的。K 要事先定。
数学表达
① c_i = argmin_k ‖x_i − μ_k‖²   ② μ_k = mean{ x_i : c_i = k }   ·   每轮 O(nKp)
中心一点点挪到位，挪到没人换队就停
本案例没用没用。本案例不做聚类（标签是算出来的，不是分组出来的）。
Python 代码（点击展开）
import numpy as np

def kmeans(X, K=3, iters=100, seed=0):
    rng = np.random.default_rng(seed)
    mu = X[rng.choice(len(X), K, replace=False)]     # 随机起点
    for _ in range(iters):
        dist = ((X[:, None, :] - mu[None, :, :]) ** 2).sum(-1)
        lab = dist.argmin(1)                          # ①派点
        new_mu = np.array([X[lab == k].mean(0) for k in range(K)])   # ②挪中心
        if np.allclose(new_mu, mu):
            break
        mu = new_mu
    return lab, mu

lab, mu = kmeans(Xs, K=3)
print("各簇人数 =", np.bincount(lab))

K 折交叉验证K-Fold Cross Validation

是什么把数据切成 K 份，轮流拿其中 1 份当考试、其余当练习，考 K 次取平均。每个人都当过一次考生。
何时用样本不多、又想比较靠谱地估计「模型到了新数据上会怎样」。是调参时的标准评估法。
怎么用分类问题用分层抽样（每折好坏比例一致）。时间序列不能随机切，要按时间切。切之前做的标准化要放进 pipeline。
数学表达
CV = (1/K) Σ_{k} 误差(在第 k 折上测试)   ·   常用 K = 5 或 10
五轮下来，每一份都当过一次考试集
本案例没用刻意没用。本案例真正的风险不是「随机折上的波动」，而是模型从「见过的人」走到「没见过的人」——K 折会把这个坑盖住。见 第 31 页 · 外推落差，切分见 step3 切训练/测试L210–229。

提前停止Early Stopping

是什么训练时盯住验证集的表现：一旦 连续若干轮不再变好，就停下来，把最好的那一版留着。
何时用迭代类模型（GBDT、神经网络）几乎必配，既省时间又防过拟合。
怎么用一定要留一块没参与训练的验证集。patience（容忍轮数）别太小，10–50 轮比较稳。
数学表达
若 metric(val) 连续 patience 轮未改善 → 停止，回退到最优轮次的模型
训练误差还在降，验证误差已经开始抬头——就该停了
本案例IRLS 每轮比偏差，delta < tol 就停——这就是提前停止：IRLS 的收敛判据L161–195
Python 代码（点击展开）
import numpy as np

def early_stop(train_loss, val_loss, patience=20):
    """返回应该停在第几轮（0-based）以及对应的最优验证损失。"""
    best = np.inf; best_i = 0; wait = 0
    for i, v in enumerate(val_loss):
        if v < best - 1e-6:
            best, best_i, wait = v, i, 0
        else:
            wait += 1
            if wait >= patience:
                return best_i, best
    return best_i, best

i, v = early_stop(tr, va)
print("停在第 %d 轮，验证损失 %.4f（继续跑到第 %d 轮只会更差）"
      % (i + 1, v, len(va)))

算法的代价：一张复杂度速查

算法单轮代价通常轮数什么时候不合适
闭式解O(np² + p³)1p 很大（几千以上）
梯度下降（全量）O(np)10²–10³n 极大时每轮太贵
小批量 GDO(bp)多轮 × (n/b)几乎都能用
牛顿法 / IRLSO(np² + p³)5–50p 上万时 Hessian 算不动
坐标下降O(np)10–10³特征高度相关时慢
CART 找切点O(np·bins)每层一次——
Lloyd（K-Means）O(nKp)10–100簇形状不是圆的

n = 样本数，p = 特征数，b = 批大小，K = 簇数。
