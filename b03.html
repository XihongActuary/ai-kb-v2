模型是什么：一个会算数的套路

别被这个词吓到。模型就是一个「丢进去、吐出来」的固定套路： 你给它一个人的资料，它还你一个数。就这么多。

本页目录
模型是个黑盒子吗 两种最常见的套路 学模型 = 找数字
往深了学 · 机器学习知识库核心三要素
这一页在讲什么

模型是什么。你每天都在用好几个模型——菜谱、体检评分表、核保规则分，它们本质上都是「输入 → 输出」的套路。

读完你会知道

学模型 = 把模型里那几个空数字填上。没有别的玄机。

模型是个黑盒子吗

很多人以为模型是个神秘黑箱。其实你每天在用模型：

你熟悉的东西输入输出它其实就是模型吗
菜谱放什么料、放多少出什么菜是
体检报告评分表各项指标健康总分是
我们的核保规则分年龄、车型、渠道规则分（拒/保）是
银行贷款审批表收入、负债、征信贷不贷是

看见了吗？我们的核保规则分，本身就是一个模型 —— 只是它的数字是人拍的。 机器学习做的，是把「人拍的数字」换成「从数据里算出来的数字」。

两种最常见的套路

左边是「一条线」型，右边是「一串问题」型。本案例两个都用了，最后把它们拼起来。

套路一：一条线（GLM / 线性回归）

公式长这样：预测值 = a + b₁×年龄 + b₂×车值 + …。 每一项都乘一个系数再加起来。它最大的好处是 —— 每个系数都能讲出业务含义。 比如算出 b₁ = −0.03，你就能直接说「年龄每涨一岁，出险率约降 3%」。 这正是精算师熟悉的语言，也是为什么这个库从它开始讲。

套路二：一串问题（决策树）

公式是一连串「是/否」问题：年龄小于 25 吗？是 → 车值大于 30 万吗？否 → … 走到最后一片叶子，就得到一个数。它的好处是能表达「拐弯」的规律 —— 比如「年轻人才在乎车值，年长的人不在乎」。一条直线表达不了这种规律，树可以。

套路怎么算的能解释吗短板
一条线（GLM）各行其是，匀速叠加能，系数就是业务含义表达不了拐弯、交叉
一串问题（树）分人群，各给一个数能，看得出走了哪条路边界是硬的，不够平滑

本案例最后用的，是把两者拼起来：频率用一条线预测，损失用一串问题预测，然后相乘。 这个思路在第 25 页会展开。

学模型 = 找数字

模型里那些 a、b₁、b₂ 叫参数（也叫系数）。 模型刚建好的时候，这些数字是空的 —— 或者干脆全是 0。 所谓的「训练模型」，就是把这些数字一个一个找出来。

说人话

模型是空的表格，参数是表格里的空格，训练就是把空格填满。 第 26 页的动画，就是一格一格填这些空格的过程 —— 你可以亲眼看着它填。

看完这一页，你只需要记住三句话
  1. 模型 = 输入 → 输出的固定套路，你每天都在用好几个。
  2. 「一条线」能解释但不会拐弯；「一串问题」会拐弯但边界生硬。本案例两者都用。
  3. 学模型 = 把模型里那几个空数字填上，没有别的玄机。
本页词语解释正文里带虚线的词，点一下也能到这里
模型一个「输入 → 输出」的固定套路。给它一个人的资料，它吐出一个数。
参数（系数）模型里那些需要「学」出来的数字。学模型 = 找这些数字。
GLM精算的老熟人：把各个因子的影响「加起来」，再套一层变换。好处是每个系数都能讲出业务含义。
决策树一串 if-else 问题：「年龄<25？是→车值>30万？否→…」走到底就得答案。
核保与承保核保 = 判断这个人能不能保、按什么条件保；承保 = 最终接下这笔业务。被拒掉的人从此就没有数据了。
渠道保单是从哪儿卖出去的（代理人、电销、网销、银保）。它常常只是「信息好不好拿到」的替身，不是风险本身。
