从你熟悉的 GLM 出发

先说一个可能让你意外的事实：你已经会机器学习了。 你上个月做费率因子的时候，用的就是它——只不过你们管它叫 GLM， 隔壁互联网公司管它叫「逻辑回归模型」。

本页目录
先记住一条考场规则 手写一遍 GLM GLM 的天花板
本页要做的三件事

把你天天在用的费率因子，翻译成机器学习的语言。你会发现：你早就会机器学习了。

目标
把你天天在做的 GLM 费率因子，翻译成机器学习的语言，看清「系数」和「特征权重」其实是同一个东西。
输出
一个能用「训练集 / 测试集」分开评价的 Poisson GLM 频率模型（核心代码就在 models.py，不到 30 行）。
怎么读
重点看左右两栏公式哪里相等；并记牢机器学习加的第一条铁律：考试不许考原题——训练集上漂亮不算数。
读完你会知道
精算叫费率因子、统计叫回归系数、机器学习叫特征权重——说的是同一个东西。

同一个公式，两种行话

车险定价里你写过无数次这个式子：

风险 = 基准风险 × 年龄因子 × 车型因子 × 区域因子 × … 精算行话：乘法费率模型，因子通过边际分析 + 判断法确定

机器学习里它长这样：

log(E[出险次数 | x]) = β₀ + β₁·年龄 + β₂·车型 + β₃·区域 + … 机器学习行话：Poisson 回归，系数通过「最小化损失函数」自动算出

两边取个指数，机器学习的式子就变成了你的式子：exp(β₁) 就是年龄因子，就是相对风险 RR。 不是类比，是同一个东西。

唯一真正的区别在于「系数怎么来」：你的流程是人先挑变量、再拟合、再看显著性、 凭经验调整；机器学习的流程是机器在同一个框架里自动搜索，再用一套统一的分数（损失函数）评价好坏。 工具一样，工作流不一样。
为什么必须是对数连接？不写 log 行不行？
λ(x) = exp(β₀ + β₁x₁ + β₂x₂ + …) = e^{β₀} · e^{β₁x₁} · e^{β₂x₂} · …

要预测的出险次数 λ 必须大于 0，而右边那个线性组合可以取任意负数——直接连会算出「负的出险次数」，没有意义。对数把「正数」映射到「任意实数」，怎么加都不会跑出正数轴。

  • λ(x) — 这个人的期望出险次数，必须 > 0
  • β₀ — 基准水平，取指数后就是基准风险
  • β₁… — 各特征的系数，取指数后就是相对风险 RR

取指数之后，加法变回乘法——这就是你写了无数遍的乘法费率模型。所以 exp(β₁) 就是年龄因子：不是类比，是同一个东西。

机器学习加的第一条规矩：考试不许考原题

你以前拟合 GLM，是拿全部数据拟合、全部数据出表——没人管这个模型「遇到陌生人」会怎样。 机器学习把这件事变成了铁律：

训练集 —— 平时的作业题

本案例 11,200 个已承保客户中留 8,400 件给机器找系数。

测试集 —— 期末考试

剩下 2,800 件封存，模型练完才准碰。考试分数（测试 AUC）才算数。

过拟合 —— 背题背出来的好学生

训练分数很高、考试崩掉，就是过拟合。GLM 因为形态简单，几乎不会过拟合—— 本案例三个模型训练→测试的衰减全部在 ±2% 以内，包括那个学习率最快的 GBDT。

训练集与测试集的 AUC 几乎重合。如果哪天你看到一个模型这两根柱子差得很远，先别看它的宣传页，先怀疑它在背题。

手写一遍 GLM：IRLS 到底在转什么

Poisson 回归的求解器叫 IRLS（迭代重加权最小二乘），名字吓人，动作只有三步：

① 用当前系数猜一遍：μᵢ = exp(β₀ + β₁xᵢ)　　② 看差距：zᵢ = ηᵢ + (yᵢ − μᵢ)/μᵢ　　③ 带权回归一遍更新系数 重复 ①②③ 直到系数几乎不动（收敛）。第 26 页的动画会把这三步逐步演给你看

本库的 models.py 里，这 30 行就是全部——没有 sklearn：

# Poisson IRLS 的核心循环（models.py 摘录）
for it in range(max_iter):
    mu    = np.exp(np.clip(X @ beta, -8, 8))       # ① 猜
    z     = eta + (y - mu) / mu                    # ② 差距 → 工作响应
    W     = mu                                     # Poisson 的权重就是 mu
    beta  = solve(X.T @ (W[:,None]*X), X.T @ (W*z)) # ③ 加权最小二乘
    if np.max(np.abs(beta - beta_old)) < tol: break
两个细节值得停一下：对数链接保证预测永远为正（保费不能是负数）； 权重 W = μ 意味着模型自动更在乎「高风险的人」——他们预测错一个，代价更大。
IRLS 和牛顿法是什么关系？为什么它比梯度下降快？
β(t+1) = β(t) − H−1 · ∇ℓ( β(t) )　　其中 H = XᵀWX，W = diag(μ)

牛顿法的思路是「用二阶导数决定往哪走、走多快」。泊松对数连接下，每一步的二阶信息刚好等价于「用权重 μ 做一次加权最小二乘」——所以 IRLS 不是另一套方法，就是牛顿法换了个写法。

  • ∇ℓ — 损失函数的一阶导数（梯度）：往哪个方向走
  • H — 二阶导数（Hessian）：路有多弯，决定步长
  • W — 权重矩阵，Poisson 下正好等于 μ

因为它用了曲率信息（H），所以收敛比普通梯度下降快得多——代价是每轮要解一个线性方程组，样本很大时会慢。

GLM 的天花板：它只会画直线

GLM 学到的东西永远是「每个变量乘一个固定系数」。年龄每涨一岁，风险永远降同样的百分比。 但真实世界里的规律常常是弯的、是拐弯的、是「35 岁以下风险陡增，以上平坦」的。 GLM 想拟合拐弯，你得自己动手造交互项、造分段——造不造，全凭人的经验。

而决策树和 GBDT 会自己从数据里找出拐点。这正是第二部分要演给你看的。

说人话

机器学习没有把你的 GLM 扔掉。它只是给你的老工具加了三个新习惯：留考卷、统一打分、 以及允许模型自己找拐弯。

管理启示

下次有人跟你汇报「我们上了机器学习定价模型」，第一个问题就问：「训练集和测试集是怎么切的？」 答不上来的，大概率是把作业题当考卷用了——数字漂亮，一上线就露馅。

特别提醒

AUC 这个词在这一页还只是「排序能力」的代号。记住一个反直觉的点： 本案例的模型要找的是风险最低的人，所以打分时用的是 −预测值。 方向搞反，你会得出「模型比乱猜还差」的结论——我们自己就踩过这个坑，测试集 AUC 一度算出 0.4。
